TASK: Standardize Safe Area across the app
	1.	In the global CSS (usually client/src/index.css or client/src/styles.css):

	•	Define safe-area variables
	•	Do NOT apply padding to :root or body directly (that causes double padding / weird header gaps)
	•	Apply safe-area padding ONLY inside a single “AppShell” wrapper.

Add:

:root {
  --sat: env(safe-area-inset-top);
  --sab: env(safe-area-inset-bottom);
  --sal: env(safe-area-inset-left);
  --sar: env(safe-area-inset-right);
}

	2.	Create or update a single top-level wrapper (commonly AppShell.tsx, Layout.tsx, or inside App.tsx) that wraps every screen.

Wrap the router output like this:

<div className="app-shell">
  {/** your header/nav here if global **/}
  <div className="app-content">
    {/* routes/screens */}
  </div>
</div>

CSS:

.app-shell {
  min-height: 100vh;
  padding-top: var(--sat);
  padding-bottom: var(--sab);
  padding-left: var(--sal);
  padding-right: var(--sar);
  box-sizing: border-box;
}

/* Important: prevent any screen from "escaping" the safe area wrapper */
.app-content {
  min-height: calc(100vh - var(--sat) - var(--sab));
}

	3.	Fix the header/topbar so it does NOT add extra top padding/margin.
Search for header CSS like padding-top, margin-top, pt-12, pt-10, safe-area, etc.

Rule:
	•	Header should start at the top of .app-shell with no extra top padding.
	•	If the header is position: sticky/fixed, it must use top: 0 (NOT top: env(safe-area-inset-top) because the shell already handles it).

Header CSS should be like:

.topbar {
  margin-top: 0 !important;
  padding-top: 0 !important;
  position: sticky;
  top: 0;
  z-index: 10;
}

	4.	Ensure DW Chat screen is inside the same wrapper.
If DW chat uses position: fixed; top: 0; height: 100vh; it will ignore the safe area.

Fix rule for chat screen containers:
	•	Replace height: 100vh with height: 100%
	•	Replace top: 0 with top: 0 ONLY if it remains inside .app-shell
	•	If it must be fixed, then set top: var(--sat) (but prefer not fixed)

TASK: Make Mood screen back button route to Today explicitly
	•	When opening Mood from Today, pass from=/today
	•	Mood back button goes to from if present, else /today

Example (works with most routers):

Back button:

const params = new URLSearchParams(location.search);

If you use router “state”:

navigate("/mood", { state: { from: "/today" }});

Back:

navigate(location.state?.from ?? "/today");
