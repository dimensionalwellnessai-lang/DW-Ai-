## 🎯 Key Features

### Time-Based Context
The menu automatically adapts based on the current time:
- **6am-11am**: Morning focus (routine, workout, breakfast)
- **11am-5pm**: Afternoon focus (lunch, check-in, progress)
- **5pm-10pm**: Evening focus (dinner, reflection, wind down)
- **10pm-6am**: Night focus (sleep prep, journal, planning)

### AI Personalization
- Tracks which features you use most
- Shows your top 4 most-used features
- Adapts over time as your habits change
- All data stored locally (privacy-first)

### Warning Banners
Shows contextual alerts when needed:
- ⚠️ "Complete Your Setup - 60% done" - if onboarding incomplete
- ⚠️ "Complete Life Dimensions" - if assessment not done
- Dismissible or actionable

### Search & Filter
The All Features view includes:
- Real-time search filtering
- Organized categories
- Scroll indicators for long lists
- 4-column grid layout for easy scanning

## 🔄 Navigation Flow

```
┌──────────┐
│   Home   │
└────┬─────┘
     │
     ├─── Hamburger Menu Button (top-left)
     │    └─── Opens HamburgerMenu
     │         │
     │         ├─── Suggested Actions (time-based)
     │         ├─── Core Items (Home, Today, Talk to DW)
     │         └─── "All Features" Button
     │              └─── Opens AllFeaturesView
     │                   │
     │                   ├─── Search Bar
     │                   ├─── Most Used (AI)
     │                   └─── Categories
     │
     └─── Bottom Nav (always visible)
          ├─── Calendar
          ├─── Browse
          ├─── Home
          ├─── DW (Talk)
          └─── Journal
```

## 🎨 Design Principles

1. **Context-Aware**: Menu changes based on time and user state
2. **Minimal Friction**: Core actions always 1-2 taps away
3. **AI-Assisted**: Learns from behavior without tracking personally
4. **Calm UI**: No aggressive notifications or pressure
5. **Optionality**: Everything is optional, nothing mandatory
6. **Backward Compatible**: Old menu still available via feature flag

## 🚀 Feature Flags

Toggle new features on/off:
```javascript
NEW_NAVIGATION: true      // ✅ Context-aware menu
ALL_FEATURES_VIEW: true   // ✅ Searchable directory
AI_PERSONALIZATION: true  // ✅ "Most Used" learning
HOME_CONSOLIDATION: true  // ✅ Unified home
```

## 📱 Mobile-First Design

- Touch-friendly tap targets (min 44x44px)
- Swipeable drawers
- Bottom nav for primary navigation
- Safe area insets for notched devices
- Dark mode support

## 🔐 Privacy & Security

- All AI learning data stored locally (localStorage)
- No server-side tracking of feature usage
- User data stays on device
- Can clear learning data anytime
- No personally identifiable information collected
